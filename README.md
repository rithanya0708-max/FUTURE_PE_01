# FUTURE_PE_01

## Tasty Bites Restaurant

This project focuses on creating professional and engaging website content for Tasty Bites Restaurant, a local restaurant based in Coimbatore. The content was developed using structured prompt engineering techniques to understand the business requirements, target audience, services, and marketing needs.

The project includes content for the restaurant homepage, services, menu highlights, and call-to-action sections. The prompts were designed to generate simple, friendly, attractive, and customer-focused website content that encourages users to explore the menu, order food, book a table, or visit the restaurant.

### AI Tools Used

ChatGPT, Claude AI, and Lovable AI were used during the content creation and website development process. Prompt Engineering was used to provide clear business information, define the target audience, specify the required output, and maintain a consistent tone and style.

### Project Files

The repository contains the business details and three structured prompts for generating homepage, services and menu, and CTA content.

### Skills Demonstrated

This project helped demonstrate skills in Prompt Engineering, AI Content Generation, Website Copywriting, Content Planning, and Marketing Communication.

### Outcome

The final result is a reusable set of AI prompts that can generate attractive and relevant website content for Tasty Bites Restaurant and can also be adapted for similar local businesses.
